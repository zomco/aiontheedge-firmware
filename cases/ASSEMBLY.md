## 开始之前

**需要准备的外购件**

| 件 | 规格 | 数量 |
|---|---|---|
| ESP32-S3-CAM | 40×27，IPEX 座 | 1 |
| 前表面反射镜 | 70×50×2，铝+SiO₂ | 1（**建议备 2 片**） |
| 5mm 草帽白光 LED | 120° 全角 | 2 |
| M4 蝶形螺丝 | | 2 |
| EVA 泡棉 | 12mm 厚，约 27×40 | 1 |
| LED 驱动板 | AO3400 + 100Ω×2 + 100kΩ，15×20 洞洞板 | 1 |
| FPC 天线 | 65×15，IPEX 尾线 50mm | 1 |

**三个打印件**：`body` / `mirror_holder` / `slide_cover`

**注意事项**

1. **反射镜的镀膜面不可擦拭**，只能气吹；划伤即报废。全程戴手套。
2. 识别镀膜面：**用笔尖轻触镜面，笔尖和倒影没有间隙的那一面就是镀膜面。**
3. 表盘上方净空只有 70mm，整机拆装需要 18.5mm 的垂直行程，动作要留出空间。

## 整机装配

顺序**不是随便排的**：抱箍必须最先固定（后面所有对位以它为基准）；板卡必须在滑盖之前（滑盖封住的正是板卡的插入口）；镜片托板必须最后（它是每月要拆、也最脆的件）。

### 1. 主体套上银圈，压到夹持带下沿到位

- **工具**：徒手
- **要点**：整机沿 −Z 落下 18.5mm。16 条内棱单边过盈 0.25mm，需要稍用力；套不进去先检查银圈上有没有漆瘤。
- **防呆**：剖分缝和夹紧耳都在 +Y 侧（面向房间），装反了螺栓够不着。
- **运动路径**（相对最终位置的偏移，mm）：(0, 0, 18.5) → (0, 0, 9.25) → (0, 0, 0)
  ．这条路径**已经过碰撞仿真**（自检 SEQ 分类），沿途和全程净空都验过。

### 2. 拧紧两颗 M4 蝶形螺栓

- **工具**：徒手（蝶形螺丝）
- **要点**：上下两颗交替拧，各拧 2~3 圈轮换，避免夹持带张成 V 形。拧到用手转不动整机为止。
- **防呆**：两颗螺栓规格相同，装不错。

### 3. 压入两颗草帽 LED

- **工具**：徒手
- **要点**：引脚先穿过座孔底部的 Ø3.2 过孔，再把法兰压进座孔。
- **防呆**：★ 座孔有极性切边，灯珠只能按唯一姿态压进去（自检 POKA-03）。

### 4. 走 LED 引线：立板竖槽 → 横槽 → 吊臂 U 型腔 → 吊舱

- **工具**：镊子
- **要点**：吊臂是**下开口**的 U 型槽，线从下方塞进去即可，不用穿。

### 5. 装 LED 驱动板（AO3400 + 电阻，15×20 洞洞板）到吊舱下部电子舱

- **工具**：热熔胶
- **要点**：放在板卡下方的空腔里，远离光学部分，散热和电子件都不靠近镜头。

### 6. 把 FPC 天线贴进 +X 内壁的定位框，馈线接 IPEX 座

- **工具**：徒手
- **要点**：馈点朝上，尾线沿内壁走到板卡位置。

### 7. 从吊舱后方推入 ESP32-S3-CAM

- **工具**：徒手
- **要点**：板下缘先落在承台上，两侧沿导轨往前推；最后 6mm 时摄像头模组会自己被方腔的导向倒角引进去。★ SD 卡（如果还用）必须**在这一步之前**插好，装上以后够不着。
- **防呆**：★ 前腔在 Z 方向不对称（SD 卡座偏上），板子上下颠倒或前后调头都进不去（自检 POKA-04/05）。
- **运动路径**（相对最终位置的偏移，mm）：(0, 26, 0) → (0, 14, 0) → (0, 6, 0) → (0, 2, 0) → (0, 0, 0)
  ．这条路径**已经过碰撞仿真**（自检 SEQ 分类），沿途和全程净空都验过。

### 8. 把 EVA 泡棉贴在滑盖内侧

- **工具**：双面胶
- **要点**：泡棉厚 12mm，装上滑盖后把板卡顶向前止挡面。

### 9. 滑盖从吊舱顶部插入，竖直下滑到底

- **工具**：徒手
- **要点**：对准顶部开口往下推，到底会有明显的落座感。
- **防呆**：★ +X 滑槽里有一条定位筋，盖板装反（上下颠倒或前后调头）都会被筋顶住（自检 POKA-02）。
- **运动路径**（相对最终位置的偏移，mm）：(0, 0, 78) → (0, 0, 40) → (0, 0, 12) → (0, 0, 3) → (0, 0, 0)
  ．这条路径**已经过碰撞仿真**（自检 SEQ 分类），沿途和全程净空都验过。

### 10. 接 5V 电源线（底部水滴孔进线）

- **工具**：徒手
- **要点**：进线孔朝下，防止楼道结露沿线倒灌。本地并 470~1000µF + 100nF。

### 11. 【台面】把前表面镜从 T 型槽端口滑入托板

- **工具**：徒手 + 手套
- **要点**：镀膜面不可擦拭，只能气吹；划伤即报废，建议多备 2 片。
- **防呆**：镜片是矩形玻璃，两面都能装 —— **这一处做不成几何防呆**。托板横梁上刻了 COATED SIDE DOWN，装之前对一眼。

### 12. 把镜片托板垂直落到四根定位销上

- **工具**：徒手
- **要点**：先从 +Y 方向平移进来，再垂直落下。四根销进孔后托板自然坐平。
- **防呆**：★ 前后销直径不同（后 Ø4 / 前 Ø5），前后调头装不上（自检 POKA-01）。
- **运动路径**（相对最终位置的偏移，mm）：(0, 30, 8) → (0, 20, 8) → (0, 10, 8) → (0, 0, 8) → (0, 0, 3) → (0, 0, 0)
  ．这条路径**已经过碰撞仿真**（自检 SEQ 分类），沿途和全程净空都验过。

## 每月人工抄表

**只动镜片托板。** 相机、镜头、抱箍全程不动，所以放回去以后 ROI 不需要重新标定。

### 1. 握住托板横梁，垂直上提 8mm 脱离定位销

- **工具**：徒手
- **要点**：横梁在 y=28~34，越过了立板前缘（y=22），手伸得进去。抬 8mm 后销全部脱开，支承片底面（z=28）也越过了灯座凸台（顶 z≈27）。
- **运动路径**（相对最终位置的偏移，mm）：(0, 0, 0) → (0, 0, 3) → (0, 0, 8)
  ．这条路径**已经过碰撞仿真**（自检 SEQ 分类），沿途和全程净空都验过。

### 2. 提起后沿 +Y 平移取出

- **工具**：徒手
- **要点**：平移到 +Y 30mm 就已经完全脱开立板和吊臂；再往前就会碰到吊舱（吊舱前表面在 y=76.5，提手横梁在 y=28~34），所以到这里就该把托板端出来，而不是继续平推。
- **运动路径**（相对最终位置的偏移，mm）：(0, 0, 8) → (0, 10, 8) → (0, 20, 8) → (0, 30, 8)
  ．这条路径**已经过碰撞仿真**（自检 SEQ 分类），沿途和全程净空都验过。

### 3. 人工读数 / 拍照

- **工具**：徒手
- **要点**：相机此时视野被完全打开。

### 4. 原路放回，确认四根销都进孔、托板不晃

- **工具**：徒手
- **要点**：★ 放回后 ROI 不需要重新标定 —— 相机、镜头、抱箍全程没动。
- **运动路径**（相对最终位置的偏移，mm）：(0, 30, 8) → (0, 20, 8) → (0, 10, 8) → (0, 0, 8) → (0, 0, 0)
